# puzzlesip-site

The public pages for the PuzzleSip Android app: a landing page and the privacy
policy that Google Play requires from any app showing ads.

Served by GitHub Pages from the `main` branch, root folder.

- https://akagiryohei.github.io/puzzlesip-site/
- https://akagiryohei.github.io/puzzlesip-site/privacy.html

The app's source lives in a separate private repository. Only these pages are
public, because the policy URL has to stay reachable for as long as the app is
listed.
